Ectoceon ROM asset source package for Pokemon: Sam Edition.

front.png / back.png are indexed 64x64 Gen III battle sources derived from the approved Ectoceon front/back implementation references.
normal.pal is the normal runtime palette; shiny.pal is derived from the approved shiny Ectoceon references while preserving the normal tile indices.
icon.png is a 32x64 two-frame party/menu icon using existing icon palette 2.
No dedicated Ectoceon footprint artwork exists in the current asset authority, so Ectoceon conservatively reuses Eevee's family footprint rather than inventing new art.
No Ectoceon overworld sprite is required by current canon.
