Leafeon ROM asset source package for Pokemon: Sam Edition.

Battle art is derived from the approved user-supplied Leafeon Gen III-style source archived in Google Drive. The PNGs in this directory are indexed implementation assets consumed by the existing gbagfx build pipeline.

front.png / back.png: normal battle tile sources
normal.pal / shiny.pal: runtime normal and shiny palettes
icon.png: party/menu icon using existing icon palette 0
footprint.png: 16x16 Pokédex footprint source
